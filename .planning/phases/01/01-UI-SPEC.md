## Color

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `--bg` | `#101312` | Page background, grid overlay |
| Secondary (30%) | `--panel` / `--panel-strong` | `#171c1a` / `#202823` | Card surfaces, sidebar, workspace panels |
| Accent (10%) | `--accent` | `#67b99a` | Reserved for: card hover border glow, active tab background, focus ring on expand trigger, connected status dot |
| Destructive | `--danger` | `#d46a5f` | Destructive actions only — none in this phase |

Accent (`--accent`) is reserved for exactly these elements in this phase:
1. Genre card hover `border-color` (via `color-mix(in srgb, var(--accent) 65%, transparent)`)
2. Genre card hover `box-shadow` glow (via `color-mix(in srgb, var(--accent) 55%, transparent)`)
3. Focus ring on expand trigger `outline` / `box-shadow` (4px ring via `color-mix(in srgb, var(--accent) 18%, transparent)`)
4. Expand chevron color after open state (inherits from parent, `var(--muted)` collapsed, `var(--accent)` open)

Secondary semantic color: `--amber` (`#d9b56f`) — not used in this phase. `--danger` present but no destructive actions exist in Phase 1.

## Component Inventory

New components required for `app/page.tsx`. Each extends existing CSS patterns.

### 1. Genre Cards Section

**Container:** `.genre-cards-section`
- Placement: Above existing `<main>` content in `app/page.tsx`
- Layout: `display: grid; gap: 12px;` matching `.prompt-grid` layout rhythm
- Section title: Use `.section-title` pattern with an `h2` at 19px

### 2. House Parent Card (expandable)

**Element:** `<details class="genre-parent-card">`

Inherits from `.vst-settings details` expand/collapse pattern:
- `summary` acts as the clickable expand trigger
- `summary h2` with `::after { content: "▸"; transition: transform 200ms ease; }`
- `details[open] summary::after { transform: rotate(90deg); }`
- Background: `var(--panel-strong)`
- Border: `1px solid var(--line)`
- Border-radius: `8px`
- Padding: `15px`
- No generic "House" prompt fires on click — expand reveals sub-genres only (D-02)
- Visual distinction from direct-click cards: parent card shows the `▸` chevron; direct-click cards show no chevron and behave as `.prompt-button`

Animation (D-04): Sub-genre grid inside `details` animates open with `transition: opacity 200ms ease` from 0 → 1 and a `max-height` slide from 0 → auto equivalent (CSS `display: grid; gap: 12px;` inside the open content).

### 3. Sub-Genre Cards (Deep House, Tech House)

**Element:** `<button class="prompt-button genre-sub-card">`

Reuses `.prompt-button` styles verbatim:
- `display: grid; gap: 18px; min-height: 128px`
- `border: 1px solid var(--line); border-radius: 8px; padding: 15px`
- `background: var(--panel-strong); color: var(--ink); text-align: left`
- Hover: `border-color: color-mix(in srgb, var(--accent) 65%, transparent)` + box-shadow glow + `transform: translateY(-2px)`
- Active: `transform: translateY(1px)`
- Transition: `border-color 160ms ease, box-shadow 160ms ease, transform 160ms ease`

Content layout inside the card:
- `<span>` — card label at 18px / weight 900 / line-height 1.05
- `<small class="genre-subline">` — subline at 12px / weight 800 / `color: var(--muted)`
- `<p class="genre-description">` — description body at 14px / weight 400 / `color: var(--muted)` / line-height 1.5

### 4. Non-Parent Genre Cards (Techno, UKG, Trap, etc.)

**Element:** `<button class="prompt-button">` — reuses existing pattern without modification.
Visual distinction from House parent card: no `▸` chevron, no `details` wrapper, single click fires prompt immediately. (D-03)

## Interaction Contract

### Expand / Collapse (House Parent Card)

- Trigger: Click anywhere on the `summary` element
- Collapsed state (default): Sub-genre cards hidden, chevron points right (`▸`)
- Expanded state: Sub-genre cards visible with 200ms fade-in, chevron rotates 90° to point down
- Animation duration: 200ms ease (D-04 from CONTEXT.md)
- Only one expand behavior in this phase (House). No accordion — multiple parents can be open simultaneously if future phases add more.
- Keyboard: `<details>`/`<summary>` native keyboard support — Enter/Space toggles. No custom JS required.
- Accessibility: `<details>` is natively accessible. `summary` receives focus styles via `var(--accent)` focus ring.

### Card Click (Sub-Genre and Direct-Click Cards)

- Single click fires the pre-written prompt template into the chat input or plan API field
- No confirmation dialog required
- No destructive action in this phase
- Click writes the card's `data-prompt` attribute value into the prompt `<textarea>` (or whichever input the page uses for `/api/finisher` `userInput`)

### Loading / Pending State

- Card click does not show a spinner on the card itself
- If the plan API is in-flight, the submit button (existing `.primary-button`) shows disabled state via `opacity: 0.55; cursor: default` — consistent with `.feedback-actions button:disabled` pattern

## Accessibility Contract

- All genre cards are `<button>` elements — native keyboard focus and activation
- House parent card uses `<details>`/`<summary>` — native keyboard expand/collapse
- Focus visible: `border-color: var(--accent)` + `box-shadow: 0 0 0 4px color-mix(in srgb, var(--accent) 18%, transparent)` on `:focus-visible` (matches existing `input:focus` style)
- Color contrast: `--ink` (#f3f0e8) on `--panel-strong` (#202823) passes WCAG AA at 14:1 ratio
- `--muted` (#b9c2ba) on `--panel-strong` passes WCAG AA for large text (card subline at 12px weight 800 qualifies as large)
- No motion: Respect `prefers-reduced-motion` — wrap `transition` declarations in `@media (prefers-reduced-motion: no-preference)` for the 200ms expand animation
